\subsection{Benzerlik Hesaplama Yöntemi}

Her model için benzerlik şu şekilde hesaplanmıştır:

\begin{enumerate}
    \item Giriş metni ve karşılaştırılacak belge tokenize edilir
    \item Her token için Word2Vec modeli üzerinden vektör alınır (modelde olmayan kelimeler atlanır)
    \item Tüm token vektörlerinin aritmetik ortalaması alınır (belge vektörü)
    \item Eğer hiç token vektörü yoksa Sıfır Vektörü (Zero Vector) atanır
    \item Giriş metni ile her belge arasında Kosinüs Benzerliği hesaplanır
\end{enumerate}

\begin{lstlisting}[style=kod, language=Python, caption={Belge Vektörü Hesaplama}]
def doc_vector(text, model):
    tokens = preprocess(text)
    vecs = [model.wv[w] for w in tokens if w in model.wv]
    if not vecs:
        return np.zeros(model.vector_size)  # Zero Vector
    return np.mean(vecs, axis=0)
\end{lstlisting}

\begin{itemize}

    \item \textbf{4 puan:} Anlamlı, açık benzerlik içeriyor

    \item \textbf{2 puan:} Kısmen ilgili ama bağlamı tutmuyor

\subsection{Değerlendirme-3: Jaccard Sıralama Tutarlılığı}

\[
\text{Jaccard}(A, B) = \frac{|A \cap B|}{|A \cup B|}
\]

16 model için hesaplanan 16$\times$16 Jaccard matrisi \texttt{data/jaccard\_matrix.csv} dosyasında mevcuttur. Heatmap görselleştirmesi \texttt{plots/04\_jaccard\_heatmap.png} olarak kaydedilmiştir.

\textbf{Temel bulgular:}
\begin{itemize}
    \item Aynı veri seti ve benzer hiperparametrelere sahip modeller 0.4--0.8 arası Jaccard skoru üretmiştir
    \item Skip-gram modelleri kendi aralarında, CBOW modelleri kendi aralarında daha yüksek örtüşme göstermiştir
    \item window=4 modelleri, window=2 modellerine kıyasla birbirleriyle daha fazla örtüşen sonuçlar üretmiştir
    \item Lemmatized ve stemmed veri setleri arasındaki modeller görece düşük Jaccard skoru (0.2--0.4) üretmiştir
\end{itemize}
