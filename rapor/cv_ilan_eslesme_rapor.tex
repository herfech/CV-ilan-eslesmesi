\subsection{Benzerlik Hesaplama Yontemi}

Her model icin benzerlik asagidaki adimlarla hesaplanmistir:

\begin{enumerate}
    \item Giris metni ve karsilastirilacak belge tokenize edilir
    \item Her token icin Word2Vec modelinden vektor alinir; modelde olmayan kelimeler atlanir
    \item Tum token vektorlerinin aritmetik ortalamasi alinir (belge vektoru)
    \item Eger hic token vektoru yoksa Sifir Vektoru (Zero Vector) atanir --- NaN/ZeroDivisionError'u onler
    \item Giris metni ile her belge arasinda Kosinus Benzerligi hesaplanir
    \item Her model icin en yuksek skora sahip Top-5 belge secilir
\end{enumerate}

\begin{equation}
\cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}{\|\mathbf{A}\| \cdot \|\mathbf{B}\|}
\end{equation}

\begin{lstlisting}[style=kod, language=Python, caption={Belge Vektoru + Zero Vector Savunma Mekanizmasi}]
def doc_vector(text, model):
    tokens = preprocess(text)
    vecs = [model.wv[w] for w in tokens if w in model.wv]
    if not vecs:                          # Hic vektor yoksa
        return np.zeros(model.vector_size) # Zero Vector
    return np.mean(vecs, axis=0)
\end{lstlisting}

\textbf{Temel bulgular:}
\begin{itemize}
    \item Ayni veri seti (lemmatized veya stemmed) ve benzer hiperparametreli modeller yuksek Jaccard skoru uretmistir
    \item CBOW modelleri kendi aralarinda, Skip-gram modelleri kendi aralarinda daha yuksek ortusme gostermistir --- mimari benzerlik siralama tutarliligini belirleyen temel faktordur
    \item window=4 modelleri, window=2 modellerine kiyasla birbirleriyle daha fazla orusen sonuclar uretmistir
    \item Lemmatized ve stemmed veri setleri arasindaki modeller gorece dusuk Jaccard skoru uretmistir; on isleme yontemi model ciktilarini onemli olcude etkilemektedir
    \item CBOW + dim300 grubu en tutarli i\c{c} grup olusturmaktadir
\end{itemize}
